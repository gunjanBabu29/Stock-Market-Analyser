# 📊 Stock Market Analyser

A web-based application built using Python, Machine Learning, and Streamlit to fetch, analyze, and predict stock market data using Yahoo Finance API.

---

## 🚀 Features

- 📅 Fetch historical stock data using Yahoo Finance API
- 📈 Visualize stock trends with interactive charts
- 🤖 Predict future stock prices using ML models (e.g., Linear Regression)
- 📊 Plot moving averages and closing prices
- 💻 Clean, responsive interface built with Streamlit

---

## 🛠 Tech Stack

- **Frontend**: Streamlit  
- **Backend**: Python  
- **Libraries**: `yfinance`, `pandas`, `numpy`, `scikit-learn`, `matplotlib`, `plotly`  
- **API**: Yahoo Finance API (via `yfinance`)
